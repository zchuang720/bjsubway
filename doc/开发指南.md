# 开发指南

## 项目架构
#### 项目分三个服务：
1. **Python 主程序**：用于处理视频流，包括视频流的读取、处理、输出等
2. **HTTP 服务**：用于提供 HTTP 网页，用于展示视频流等（紫通需要该服务给出网页嵌套到他们的系统中展示视频）
3. **RTSP 格式转流服务**：用于将 RTSP 视频流转换为 HTTP 视频流，用于在网页中播放视频流

#### 目录结构
```
.
├── internal        // 主要业务逻辑，包括各个场景的检测、告警逻辑等
│   ├── fire            // 动火场景
│   ├── pipe_ground     // 明挖场景
│   ├── tunnel          // 暗挖场景
│   └── ...
│
├── outs            // 程序输出目录
│   ├── alarm_images    // 告警图片
│   └── playback        // 告警回放视频
│
├── utils               // 工具类
│   └── yolo_dataset    // yolo数据集工具
│
├── web             // WEB 服务项目
│   ├── http            // HTTP 网页
│   └── rtsp2web        // RTSP 视频格式转流服务，用于将 RTSP 视频流转换为 HTTP 视频流
│
├── logs            // 日志目录
├── resources       // 资源文件，字体等
├── weights         // 存放模型权重
│
├── config.py       // 运行配置
├── properties.py   // 业务配置
├── handler.py      // 视频流检测通用框架
└── main.py
```

## 安装指南
### 需要安装的软件
1. 视频流软件，如 Easydarwin
1. ffmpeg
1. NodeJS & npm
1. python 及项目依赖库

### 安装 npm 依赖
``` bash
# 进入 rtsp2web_server 目录
cd web/rtsp2web_server

# 安装 npm 依赖
npm install

# 替换 rtsp2web.js 文件
mv node_modules/rtsp2web/dist/rtsp2web.js node_modules/rtsp2web/dist/rtsp2web.js.bak
cp dist.rtsp2web.js node_modules/rtsp2web/dist/rtsp2web.js node_modules/rtsp2web/dist/rtsp2web.js
```

## 运行方法
1. 启动视频流软件，如 Easydarwin
1. 启动 web 服务
    ``` bash
    node web/http/server.js
    node web/rtsp2web_server/index.js
    ```
1. 启动主程序
    ``` bash
    python main.py
    ```
    或
    ``` bash
    python test.py
    ```


## 部署指南
在新的标段部署时需要进行以下工作：

### 映射网络端口
1. 视频推流端口：25544
1. HTTP 服务端口：6101
1. RTSP 转流服务端口：6102

以上端口号需要映射暴露到公网，以便紫通系统能够访问到视频流。端口号可按需修改或增加。

### 修改 properties.py
更新以下信息为新标段的信息：
1. 标段各个摄像头的视频流地址
1. 紫通的告警接口地址（一般不变）
1. 标段 SN 码
1. 该标段的公网 IP 地址

具体查看 properties.py 文件

### 修改 web/http/server.js
修改代码中以下内容：
```
const serverIP = '219.143.40.102';  // 标段的公网 IP
const srcPort = 25544;              // 视频流软件的推流端口（如 Easydarwin 的 RTSP 端口）
const forwardPort = 6102;           // RTSP转流服务端口
```

### 修改 web/rtsp2web_server/index.js
修改代码中以下内容：
```
let port = 6102     // RTSP转流服务端口
```

### 视频流访问相关
HTTP 服务会把原本 RTSP 流的地址路由为 /stream 开头的地址，例如：

在 python 主程序中能够传入推送视频流的地址：
```python
push_addr = 'rtsp://localhost:25544/fire/channel01'
```
则在网页端的访问地址为：
```
http://{公网IP}:25544/stream/fire/channel01
```

为了方便管理，HTTP 服务目前一共存在两种路由：
1. /stream：访问直播视频流
1. /playback：访问告警回放视频流（beta）

详细查看 web/http/server.js 代码
